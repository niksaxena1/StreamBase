## Exclusion / consolidation decisions

The Original dashboards UI exposes all seven registry dashboards, expands follower
template instances lazily, and renders implemented panels with their saved field
configuration. Exclusions below remain explicit; consolidated entries link to
Archive → Raw observations / Followers → Raw readings. The curated Tax page uses
stats2 Tax V2 registry panels only. See [ORIGINAL-MODE.md](ORIGINAL-MODE.md).

- `stats2.spotify-dash.112` **Daily Streams: ${artist_name}** (excluded): exact duplicate (same type, title and SQL) of panel 25
- `stats2.spotify-dash.109` **Daily Streams: ${artist_name} - ${track_name}** (excluded): exact duplicate (same type, title and SQL) of panel 34
- `stats2.spotify-dash.49` **Database View** (consolidated): consolidated -> Explorer 'Raw observations' table (Archive > tracks), filterable and paged; original SQL is just SELECT ... FROM tracks LIMIT 100000 with no ORDER BY
- `stats2.tax-v2.68` **Already Accounted** (excluded): external Google Sheets datasource - data not in archive
- `stats2.tax-old.34` **Prelude RouteNote: Bar Graph** (excluded): original SQL fails in PostgreSQL itself (column "period" does not exist: the first UNION branch has no column aliases) - the panel never worked in Grafana; validated as error parity
- `stats.spotify-dash.122` **Google Sheets Integration** (excluded): external Google Sheets datasource - data not in archive
- `pf.playlist-followers.1` **Simple Table** (consolidated): consolidated -> Explorer 'Followers raw readings' table; original is the whole spotify_followers table ordered by timestamp
- `pf.playlist-followers.60` **Panel Title** (excluded): test panel with the default title 'Panel Title' (noise)
